## Service Worker Caching

### Cached Assets
**Static Cache (v1.0.0):**
- All HTML pages
- CSS files (style.css, auth.css, admin.css, windows-gui.css)
- JavaScript files
- Company logo
- Font Awesome icons
- Firebase SDK

**Runtime Cache:**
- Menu item images
- User-uploaded content
- Dynamic API responses

### Cache Strategy
1. **Cache First:** Try cache, fallback to network
2. **Network First:** For Firebase and external APIs
3. **Stale While Revalidate:** Update cache in background

### Cache Updates
- Automatic version checking
- Update banner appears when new version available
- Users can update with one click
- Old caches automatically deleted

1. **Deploy to web host with SSL:**

## Troubleshooting

### Install Banner Not Showing
**Causes:**
- Not served over HTTPS (use TEST-PWA.bat for local testing)
- Already installed
- User dismissed it recently
- Browser doesn't support PWA

**Solutions:**
- Use `localhost` for testing
- Check console for errors (F12)
- Clear cache and reload
- Try Chrome/Edge browser

### Service Worker Not Registering
**Check:**
1. Console for errors (F12 → Console)
2. Application tab → Service Workers
3. File path is `/sw.js` (root directory)
4. HTTPS or localhost

**Fix:**
```javascript
// Clear registration and re-register
navigator.serviceWorker.getRegistrations().then(registrations => {
    registrations.forEach(r => r.unregister());
    window.location.reload();
});
```

### Icons Not Loading
**Check:**
- Files exist in `images/icons/`
- PNG format (not JPEG)
- Correct sizes
- File names match manifest

**Fix:**
```powershell
# Re-create icons
TEST-PWA-ICONS.bat
```

### App Not Installing on iPhone
**iOS Requirements:**
- Use Safari (not Chrome)
- Manual installation only ("Add to Home Screen")
- No automatic install prompt
- Limited PWA features

### Offline Mode Not Working
**Check:**
1. Service Worker is registered
2. Assets are cached (Application → Cache Storage)
3. Go offline (DevTools → Network → Offline)
4. Reload page

- Cannot access cookies from other domains
- Same-origin policy applies
- Regular security updates recommended

### Manifest Security
- Hosted on same origin
- JSON validation on load
- Icons must be same origin or CORS-enabled

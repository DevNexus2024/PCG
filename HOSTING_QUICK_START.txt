  ⏱️  Time: 5 MINUTES
  💰 Cost: 100% FREE
  📦 Method: GitHub Settings
  🔧 Setup: Very Easy

  HOW TO DEPLOY:

  1. Push code to GitHub
  2. Repo → Settings → Pages
  3. Source: main branch, / root
  4. Save
  5. Wait 2 minutes
  6. Done!

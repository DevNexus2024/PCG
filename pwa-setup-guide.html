PWA Icon Generator Instructions

📱 Creating App Icons for PWA

To create the required app icons, follow these steps:

Option 1: Use an Online Tool (Recommended)

  1. Visit PWABuilder Image Generator
  2. Upload your logo: images/images_(1).jpeg
  3. Download the generated icons package
  4. Extract the icons to the images/icons/ folder

Option 2: Manual Creation

Create the following icon sizes using an image editor (Photoshop, GIMP, Canva, etc.):

  • 72x72 pixels → images/icons/icon-72x72.png
  • 96x96 pixels → images/icons/icon-96x96.png
  • 128x128 pixels → images/icons/icon-128x128.png
  • 144x144 pixels → images/icons/icon-144x144.png
  • 152x152 pixels → images/icons/icon-152x152.png
  • 192x192 pixels → images/icons/icon-192x192.png
  • 384x384 pixels → images/icons/icon-384x384.png
  • 512x512 pixels → images/icons/icon-512x512.png

Option 3: Use Windows Paint (Simple)

  1. Open images/images_(1).jpeg in Paint
  2. Click "Resize" and resize to 512x512 pixels
  3. Save as PNG: images/icons/icon-512x512.png
  4. Repeat for other sizes

📸 Creating Screenshots (Optional)

For better app store presence:

  1. Open your website in a browser
  2. Take a desktop screenshot (1280x720) → images/screenshots/desktop.png
  3. Take a mobile screenshot (540x720) → images/screenshots/mobile.png

✅ Verification

After creating icons, verify your PWA setup:

  1. Open Chrome DevTools (F12)
  2. Go to "Application" tab
  3. Check "Manifest" section - all icons should be listed
  4. Check "Service Workers" section - service worker should be active

🚀 Testing Your PWA

  1. Serve via HTTP: PWA requires HTTPS or localhost 
    # PowerShell - Simple HTTP Server
python -m http.server 8000
# Then open: http://localhost:8000
  2. Check Install Banner: Open the website and you should see the "Install App" banner at the bottom
  3. Install PWA: Click "Install" and the app will be added to your device
  4. Mobile Testing: Access from your phone browser (use your computer's IP address)

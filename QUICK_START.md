## 📌 Create a Desktop Shortcut

To make it super easy to launch:

1. **Right-click** on `LAUNCH-DESKTOP-APP.bat`
2. Select **Send to** → **Desktop (create shortcut)**
3. **Rename** the shortcut to "Pizza Club and Grill"
4. **Done!** Now you can launch from your desktop

### Optional: Add a Custom Icon

1. Right-click your desktop shortcut → **Properties**
2. Click **Change Icon**
3. Click **Browse** and select an icon from your `images` folder
4. Click **OK**

## 🔧 How It Works

The launcher:
- Finds Chrome or Edge on your computer
- Opens it in "app mode" (no browser bars)
- Loads your website from the local files
- Creates a window that looks like a native desktop app

**App mode** removes all browser UI, making it look and feel like a real desktop application!

## 🆘 Troubleshooting

### "Chrome or Edge not found"
- Install Google Chrome OR Microsoft Edge (both free)
- Restart after installation

### Website doesn't load
- Make sure all your website files are in the same folder
- Try opening `index.html` directly in browser first

### Launcher closes immediately
- Right-click `LAUNCH-DESKTOP-APP.bat`
- Select "Edit" to see any error messages
